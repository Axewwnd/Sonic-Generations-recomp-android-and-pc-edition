# XenosRecomp Integration

This directory vendors XenosRecomp (https://github.com/Player124413/XenosRecomp) for shader translation.

## What is XenosRecomp?

Tool that converts Xbox 360 shader binaries to HLSL, then recompiles to DXIL (D3D12) and SPIR-V (Vulkan) via DXC.

Based on Unleashed Recompiled's shader recompiler.

## Files

- `shader_common.h` - shared constants and helpers for translated shaders
- `shader_recompiler.h/cpp` - main recompiler logic (Xbox360 ucode -> HLSL)
- `dxc_compiler.h/cpp` - compiles HLSL to DXIL/SPIR-V via DXC
- `shader.h` - shader container parsing
- `xcompress.h/cpp` - Xbox 360 file decompression (XMemCompress)

## Usage

### Generate shader cache for Sonic Generations

1. Extract shaders from game:

```bash
# Game has shader archives: shader_r.ar.00, shader_r.ar.01 etc.
# Or embedded in default.xex

# Use XenosRecomp to scan directory:
XenosRecomp /path/to/game/shaders shader_cache.cpp XenosRecomp/shader_common.h --api vulkan --jobs 8
```

This generates `shader_cache.cpp` with precompiled SPIR-V.

2. For this port, we have GitHub Actions workflow that does it:

- Go to https://github.com/Player124413/XenosRecomp/actions/workflows/recompile-shaders.yml
- Run workflow, paste link to archive with shaders
- Download artifact `shader-cache-*` which contains `shader_cache.cpp`

Artifact from run 35902522900: https://github.com/Player124413/XenosRecomp/actions/runs/35902522900/artifacts/10770056313

Contains 6404 shaders for Sonic Generations (from earlier research).

3. Place `shader_cache.cpp` in `port/src/native/hedgehog/` and it will be used at runtime via hash lookup (XXH3).

### Integration in this port

`hedgehog/shader_translator.h/cpp` uses XenosRecomp logic:

```cpp
auto translated = ShaderTranslator::Get().Translate(xboxBytecode, size, type);
// Internally uses XenosRecomp::ShaderRecompiler to decompile to HLSL
// Then DXC to compile to SPIR-V
```

`hedgehog/shader_cache.h/cpp` loads precompiled cache:

```cpp
// shader_cache.cpp generated by XenosRecomp
// Contains array of {hash, spirv, dxil}
extern const ShaderCacheEntry g_shaderCache[];
extern const size_t g_shaderCacheCount;

auto* entry = FindShaderInCache(hash);
if (entry) {
    return CreateShaderFromCache(entry);
} else {
    return TranslateAtRuntime(bytecode);
}
```

### Performance

- Precompiled cache: no runtime translation, instant load
- Runtime translation: decompile + DXC compile = 10-50ms per shader, stutter
- Cache is compressed with smol-v + zstd for small size

### Building XenosRecomp

```bash
cmake -S XenosRecomp -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
./build/XenosRecomp --help
```

Requires DXC (DirectX Shader Compiler) for DXIL/SPIR-V compilation.

### For Sonic Generations

- 6404 shaders (from VULKAN.md in main repo)
- All SPIR-V modules verified
- Need to generate cache with --api vulkan for Android (half size, no DXIL)
